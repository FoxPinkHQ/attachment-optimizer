Key features

Migration pipeline

Analyze, queue, upload, verify and finalize attachment migration to S3 storage with full audit trail.

Dashboard

Kanban dashboard showing storage mappings grouped by status. Monitor migration progress at a glance.

S3 bridge

Configurable S3-compatible storage. Supports AWS S3, MinIO, and any S3-compatible object store.

Checksum verification

SHA-256 checksum verification after upload ensures data integrity before marking mappings as finalized.

Transparent serving

Finalized attachments are served directly from S3 via Odoo's binary controller — seamless to end users.

Audit log

Every migration action is logged with timestamps. Complete audit trail for compliance and troubleshooting.

Retry & resume

Failed uploads can be retried individually or in bulk. Idempotent design prevents duplicate mappings.

Access control

Role-based access for managers. ACL-enforced security — menus visible but data protected by model permissions.

Getting started

Storage Optimization app — access from main menu after installation

1
Install module from Apps. After install, Storage Optimization appears in the top menu bar.
2
Add user to Storage Optimization Manager group: Settings → Users, check group under Storage Optimization category.
3
Configure S3: Settings → System Parameters → set attachment_storage.s3.* keys.
4
Open Dashboard and click Action → Create Migration Queue to scan attachments.
5
Review queue in Migration Operations. Click Upload to S3 to start migration.
✓
Done — attachments served from S3 automatically!

Frequently asked questions

?
Is this module really free?

Yes. Licensed under LGPL-3, the same permissive license as Odoo Community itself. No paywalls, no premium features, no subscription required.

?
Does it work with Odoo Enterprise?

Yes. The module is compatible with both Community and Enterprise editions. No Enterprise modules are required as dependencies.

?
Are original attachments deleted from the filestore?

No. The module creates a storage mapping pointing to S3 while the original attachment remains in Odoo's filestore. You can safely revert at any time.

?
Which S3 providers are supported?

Any S3-compatible object store: AWS S3, MinIO, DigitalOcean Spaces, Wasabi, Backblaze B2, and more. Configure endpoint, region, access key and secret key in system parameters.
